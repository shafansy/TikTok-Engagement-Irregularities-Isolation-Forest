# Detection of Engagement Irregularities in TikTok Endorsement Content for a Skincare Brand An Isolation Forest Approach
## Overview

This project focuses on detecting engagement irregularities in TikTok endorsement content for a skincare brand using an unsupervised machine learning approach.

The study analyzes engagement patterns across TikTok endorsement content from different Key Opinion Leader (KOL) tiers and identifies posts whose engagement patterns differ from the majority of posts within the same KOL tier.

The anomaly detection method used in this project is **Isolation Forest**.

The analysis focuses on engagement-based metrics, including:

- Engagement Rate (ER)
- Like-to-View Ratio (LVR)
- Comment-to-View Ratio (CVR)
- Share-to-View Ratio (SVR)

After exploring the relationships among the engagement metrics, **ER and LVR** were selected as the features used in the final anomaly detection model.

The final model identified **10 posts with potential engagement irregularities** from 150 TikTok endorsement posts.

## Dataset

The dataset consists of TikTok content collected from a skincare brand's endorsement campaign.

The complete dataset contains **300 TikTok posts**, consisting of:

- 150 endorsement posts
- 150 non-endorsement posts

For the anomaly detection stage, only the **150 endorsement posts** were used.

The endorsement dataset consists of five KOL tiers:

- Nano
- Micro
- Midi
- Macro
- Mega

Each KOL tier contains **30 endorsement posts**.

The data was collected from TikTok content published between **June and October 2025**.

### KOL Tier Classification

| KOL Tier | Followers |
|---|---:|
| Nano | 1,000–10,000 |
| Micro | 10,000–50,000 |
| Midi | 50,000–100,000 |
| Macro | 100,000–1,000,000 |
| Mega | >1,000,000 |

## Engagement Metrics

Four derived engagement metrics were calculated to represent the engagement characteristics of each TikTok post.

### Engagement Rate (ER)

Engagement Rate represents the overall level of audience interaction relative to the number of views.

### Like-to-View Ratio (LVR)

LVR represents the proportion of views that resulted in likes.

### Comment-to-View Ratio (CVR)

CVR represents the proportion of views that resulted in comments.

### Share-to-View Ratio (SVR)

SVR represents the proportion of views that resulted in shares.

These metrics allow engagement to be analyzed relative to the exposure received by each post rather than relying only on absolute interaction counts.

## Feature Selection

The four derived engagement metrics were explored as potential features for the anomaly detection model:

- ER
- LVR
- CVR
- SVR

Different combinations of these metrics were evaluated to determine a suitable representation of engagement patterns.

Based on the feature exploration, **ER and LVR** were selected as the final features for the Isolation Forest model.

The final feature set was:

- **ER**
- **LVR**

Before modeling, the selected features were standardized using `StandardScaler`.

---

## Isolation Forest

Isolation Forest is an unsupervised machine learning algorithm designed to identify observations that are easier to isolate from the majority of observations.

The method was selected because the dataset does not contain ground-truth labels indicating which TikTok posts are truly anomalous.

In this project, Isolation Forest was used to identify posts whose combinations of ER and LVR differ from the typical engagement pattern within each KOL tier.

The model was applied separately to each KOL tier.

## Results
### Anomaly Detection Result
Using the final Isolation Forest configuration and the selected features ER and LVR, the model identified 10 potential engagement anomalies from the 150 endorsement posts.

The detected anomalies were identified across all five KOL tiers.

### Anomaly Score
Isolation Forest generates an anomaly score for each observation.

In the Scikit-learn implementation used in this project, the decision_function() score uses 0 as the decision threshold:

- Score < 0: anomaly
- Score > 0: normal observation

A lower score indicates a stronger indication that an observation differs from the majority pattern identified by the model.
The anomaly score is not a probability of an observation being anomalous.

The model identified the following anomaly scores among the detected posts:

| Post Code | KOL Tier | Anomaly Score | Classification |
|---|---|---:|---|
| `post_173` | Macro | **-0.228519** | Anomaly |
| `post_288` | Midi | **-0.127566** | Anomaly |

For comparison, examples of observations classified as normal were:

| Post Code | KOL Tier | Anomaly Score | Classification |
|---|---|---:|---|
| `post_16` | Midi | 0.207036 | Normal |
| `post_138` | Midi | 0.205711 | Normal |

The negative scores of `post_173` and `post_288` place these observations below the model's decision threshold and result in their classification as anomalies.

Among these examples, `post_173` has a lower anomaly score than `post_288`, indicating a stronger deviation from the majority engagement pattern according to the model.

> **Note:** The complete list of detected anomaly post codes is provided in the table above. The anomaly-score table presents the scores explicitly documented in the analysis.

## Interpretation of Results

The posts identified by Isolation Forest represent **potential engagement irregularities**.
An anomaly indicates that the combination of ER and LVR for a post differs from the typical engagement pattern within its KOL tier.
The detection result does **not** automatically indicate fake engagement, engagement manipulation, or fraudulent activity.
Instead, the model identifies posts with statistically unusual engagement patterns that may warrant further investigation.
